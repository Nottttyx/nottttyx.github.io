## 🌱 What Is AgentGarten?

AgentGarten is a garden for agents. Each "code world" is a small simulated space with its own rules, objects, and challenges. You place an agent inside, and the agent learns by trying things out — looking around, testing ideas, and gradually getting better at the task in front of it.

Because AgentGarten supports multiple kinds of input at once (text, images, and sound-style signals), agents can understand richer situations than plain text alone. And because they are built to evolve, each agent keeps improving the longer it stays in its world.

Think of it as a greenhouse for helpful software. You provide the soil and the sunlight; the agent does the growing.

## 🛠️ Troubleshooting Basics

**The app will not open.** Restart your computer and try again from the Start menu. If the setup did not complete, run the downloaded file once more and finish all the steps.

**Windows shows a security message.** Click **More info**, then **Run anyway**. This is standard for newly released software and appears until enough people have run it.

**The world view looks slow or choppy.** Close other large applications, then reopen AgentGarten. Lower the visual quality in the Settings screen if the previews still feel sluggish.

**My worlds disappeared.** Check the storage location listed in Settings. If you moved folders around, point AgentGarten back to the correct place.

**The download stopped partway.** Delete the partial file from your Downloads folder and start the download again.

**Do I need to know how to code?** No. Every action in AgentGarten is done through buttons, menus, and sliders.

**Does it work on Mac or Linux?** This guide covers Windows. Check the download page for other platforms.

**Can I have more than one agent in a world?** Yes. Most worlds support several agents at once, and watching them interact is one of the more interesting parts of the app.

**How long does an agent take to improve?** Short sessions show small changes; longer sessions show more. Progress timelines make the difference easy to see.

**Can I start over completely?** Yes. The reset button returns any world to its original state, and you can delete saved worlds from the Garden View.
